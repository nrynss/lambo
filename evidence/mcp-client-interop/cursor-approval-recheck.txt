CONCLUSION

Neither gotcha has been fixed by the client, and neither was an artifact of an
unauthenticated account. The model still selected correct arguments for all three tools
— the arguments it printed are well-formed — so the failure is purely the per-call
approval gate, not tool discovery and not the model's understanding of the schema.

`--force` (bounded by `--sandbox enabled`) remains required for a model-driven run in
non-interactive print mode.
