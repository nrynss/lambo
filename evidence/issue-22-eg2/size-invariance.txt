# Reading it
# - solid: bit-identical vector at every size after canonicalization (before: 0.999015
#   above 768 px, the 17x17 vs 16x16 patch grid).
# - checker / gradient above 768 px: every pair of renders agrees to >= 0.99978 / >= 0.99957,
#   and each is >= 0.99911 / >= 0.99969 from the native 768 px drawing. Not bit-identical:
#   a downscaled hard edge is not the crisp edge drawn at 768 px.
# - at or under 768 px the bytes are sent unchanged (vectors as v1 gave them); the server
#   resamples each to 816x816 itself, so a patterned picture's small renders differ
#   (checker 256 px 0.9848). No client downscale can change that.
#
# Filter choice: the same run with Catmull-Rom (llama.cpp's own a = -0.5 cubic) gave
#   checker vs 768: 0.999705 0.999033 0.998760 0.998612 (1024..3000), worst pair 0.999434
#   gradient vs 768: 0.999749 0.999684 0.999718 0.999735, worst pair 0.999636
# Lanczos3 is better on the hard edges and within 0.0001 on the smooth picture: chosen.
#
# WebP: b11517 decodes WebP only by running ffmpeg/ffprobe from its PATH
# (mtmd-helper.cpp decode_webp_with_ffmpeg). With ffmpeg on PATH a lossless WebP embeds
# exactly as the same PNG; with PATH=/usr/bin:/bin the server answers
#   500 {"message":"Failed to load image or audio file"}  (log: probe: failed to launch ffprobe)
# so lambo-eg2-v2 always sends a WebP as a lossless PNG (cos above: webp vs png = 1.000000).
