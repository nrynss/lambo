# Reading it
# - solid: bit-identical vector at every size from 128 to 3000 px (before: 0.999015 above
#   768 px, the 17x17 vs 16x16 patch grid).
# - patterned pictures are NOT bit-identical across sizes, and cannot be: a picture drawn
#   at 3000 px and scaled to 768 is not the picture drawn at 768 px, and a 128 px picture
#   enlarged to 768 lacks detail the 768 px one has.
#   - renders at 768 px and above: every pair >= 0.999112 (checker), >= 0.999565 (gradient)
#     (before: 0.9797 / 0.9978 to the 768 px render).
#   - all sizes 128 to 3000 px: every pair >= 0.981761 (checker, 128 vs 768),
#     >= 0.999448 (gradient). Below 768 px the canonical form matches or beats the
#     server's own resampling (checker 512 px: 0.991750 against 0.989916 before).
# - webp vs png of the same pixels: bit-identical (both become the same canonical PNG).
#
# Filter choice.
# Downscale (earlier run, same pictures): Lanczos3 beat Catmull-Rom on hard edges
#   checker vs 768 at 1024..3000: Lanczos3 0.999703 0.999333 0.999199 0.999112,
#   Catmull-Rom 0.999705 0.999033 0.998760 0.998612; gradient within 0.0001.
# Upscale (this round, cosine to the 768 px render at 128 / 256 / 512 px):
#   checker  Lanczos3   0.980228 0.979604 0.994841   (rings on enlarged hard edges)
#            CatmullRom 0.981761 0.984802 0.991750   (chosen)
#            Triangle   0.981764 0.984797 0.987042
#   gradient Lanczos3   0.999219 0.999782 0.999836
#            CatmullRom 0.999592 0.999787 0.999813
#            Triangle   0.999642 0.999771 0.999832
#   Catmull-Rom has the best worst case (0.9818 against Lanczos3's 0.9796).

# Grid check (b11517 calc_size_preserved_ratio): with the longer side at exactly 768, each
# side aligns to max(48, round48(side)) <= 768, so the aligned area is <= 589,824 px,
# under 645,120 (280 x 2,304): every canonical image takes the round-up branch, for every
# aspect ratio including a 1 px shorter side (unit test
