A live window onto what one set of agents remembers.

Coding agents forget everything when a session ends, and they cannot see what another agent already worked out. Lambo keeps that knowledge as a graph, gives it back by meaning rather than by keyword, and marks which memories other work depends on, so an agent knows what is dangerous to change.

What happened here

Two agents built real AWS infrastructure: a network with subnets and shared security groups, a private database, and a stats function. They recorded what they did as they went. Everything on this page is read live from that session.

The thing worth trying

Ask what depends on the shared security group. Lambo names the workloads that would break and counts them. That warning is what stops one agent deleting the thing another agent's database is sitting behind, and it is not something plain vector search can produce.

Ask the memory

Not a chat, and not a search box over documents. This asks the same question an agent asks before it acts, and what comes back is the exact block of memory Lambo would hand that agent, character for character.
