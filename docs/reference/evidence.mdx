<Note>
The audit also quantified four concrete failure and friction modes that drove follow-up issues:
1. **Canonical-first warning fatigue (`#280`):** `53.8%` (`14/26`) of audited warnings were ignored or false positives (`26.9%` acted on, `19.2%` noted only) because `src/recall/assemble.rs` attaches high-blast-radius Canonical banners (such as `ca2cb7d7`) even to unrelated queries.

## Recall calibration, fusion, selection, and multimodal

### Evaluation set (`#190`) and per-contract calibration (`#87`)

Lambo's recall constants were originally chosen on BGE-M3's cosine distribution (`RECENT_SCORE = 0.35`, unset layer floor `0.50`, merge threshold `0.85`). Other embedding models sit on narrower or shifted cosine scales, so Lambo calibrates measured contracts on the `#190` evaluation set (`fixtures/eval/`: 100 concepts, 310 → 368 queries, 403 labelled pairs plus 144 `#198` pairs; [`evidence/eval-set/`](https://github.com/nrynss/lambo/tree/main/evidence/eval-set)) using dev-only quantile matching against BGE-M3, then confirms on the untouched held-out split. Under self-framed candle BGE-M3, baseline vector retrieval scores `hit@1 = 0.779`, `hit@5 = 0.941`, `hit@10 = 0.966`, and `nDCG@10 = 0.876` across 204 answerable queries.

### Recall fusion (`#173`), redundancy selection (`#181`), and suspected supersession (`#198`)

- **Reciprocal rank fusion ([`evidence/issue-173-fusion/`](https://github.com/nrynss/lambo/tree/main/evidence/issue-173-fusion)):** Evaluated on the expanded 368-query set (`runs-v2`), `[fusion] kind = "rrf"` at `k = 3` (weights `1.0 / 1.0 / 0.3`) lifts overall nDCG@10 over `max` on `dev` (`0.790 → 0.854` BGE-M3; `0.849` EG2) and `held_out` (`0.840 → 0.872` / `0.863`), with large vocabulary-mismatch gains (`0.446 → 0.657` dev). Because held-out exact-identifier (`0.948 → 0.899`) and contrast (`0.912 → 0.879`) queries dip, `max` stays the global default and RRF is opt-in (except Qwen3 Embedding 4B, where `#221` showed BM25 drowned Qwen's narrower vector band). Literature `k = 60` collapses inside Lambo's 50/50 daemon blend (`0.698` dev nDCG@10).
- **Redundancy-aware selection ([`evidence/issue-181/`](https://github.com/nrynss/lambo/tree/main/evidence/issue-181)):** On duplicated corpora (`dup`, 500-token budget, `top_k = 3`), `[selection] skip_redundant = true` (same-content default) raises distinct memories rendered from `1.44 → 2.05` (dev) and `1.45 → 2.03` (held-out) and facet coverage from `0.830 → 0.849` / `0.840 → 0.881`, with **`0` false suppressions** across all contrast families and `+4 to +5 µs` p50 overhead on clean recalls. `similar_signals` stays off by default because in the decision run it gained 3 duplicate facets at a cost of 42 contrast facets before the stricter claim guard was introduced.
- **Suspected undeclared supersession ([`evidence/issue-198-trigger/`](https://github.com/nrynss/lambo/tree/main/evidence/issue-198-trigger)):** The "one span and value slot" trigger on identifier-guard-refused near matches achieves **`0.97` precision** (95% Wilson lower bound `0.86`, `35/37` recall) on dev and **`0.96` precision** (lower bound `0.81`, **`25/25` recall**) on held-out under BGE-M3, with the Rust implementation matching the Python reference row for row. Unmeasured contracts emit only the structured `possibly_superseded_by` field by default.

### Layer floor vs store size (`#254`)

Two studies ([`evidence/layer-floor-size/`](https://github.com/nrynss/lambo/tree/main/evidence/layer-floor-size) and [`evidence/issue-254/`](https://github.com/nrynss/lambo/tree/main/evidence/issue-254)) measured how fixed cosine cutoffs behave as a session or shared layer grows:

- On real logged recall queries scored against unrelated stand-in layers under BGE-M3 (`0.50` floor), the share of queries admitting at least one unrelated hit rose from `15.2%` / `37.4%` (uncorrected / corrected) at 8 concepts to `91.7%` / `98.7%` at 1,024 concepts on project A. (Arrival-order testing on merge thresholds up to 5,599 concepts showed no consistent growth.)
- Testing an empirically size-scaled floor (`#254` option 2) failed acceptance: holding unrelated admission level pushed the floor high enough to reject **`37%` (dev) / `45%` (held-out)** of grade-2 relevant pairs at 100 concepts and **`71%` / `76%`** at 1,024 concepts. No size-scaled floor was shipped; instead `lambo stats` prints `calibration=calibrated (layer floor measured on N concepts)` so large layers stay visible to operators.

### Multimodal EmbeddingGemma 2 (`#22`)

Measured live on `llama.cpp` b11517 serving `embeddinggemma-2-Q8_0.gguf` + `--mmproj` ([`evidence/issue-22-eg2/`](https://github.com/nrynss/lambo/tree/main/evidence/issue-22-eg2)):

- Text and image embeddings produce unit-norm 768-d vectors (with MRL truncation verified at 256-d). Each generated image ranked its own caption first (`0.750–0.794` cosine vs `0.566–0.678` for other captions).
- Canonical `lambo-eg2-v2` framing resizes every PNG/JPEG/WebP to a 768 px longer side before sending lossless PNG: renders at 768 px and above agree to `≥ 0.9991` cosine (flat images `1.000000`).
- Discovered that default `llama-server` ubatch (`512`) silently caps `--image-max-tokens 280` to `256` tokens, shifting vectors (`0.9989` cosine). Lambo now verifies `/props` and embeds a 1×1 reference PNG (`293 ± 8` prompt tokens at the 280 budget) to fail closed on misconfigured servers.

## Durability, concurrency, multi-client, and determinism

### Concurrency, SIGTERM durability, and SIGKILL crash boundary

- **K=12 concurrent MCP clients + mid-burst SIGTERM ([`evidence/concurrency/`](https://github.com/nrynss/lambo/tree/main/evidence/concurrency)):** 3,423 calls recorded, rate-limit `429` overdrive (`1,682` refused) and `32/32` session-cap `503` verified live. SIGTERM mid-burst exited cleanly in `1,419 ms` (`exit 0`) with the exact line `lambo serve: session closed, tail durable` (`0` `tail lost on exit`). Store readback held `862` interactions vs `841` ledger-acked writes (store AHEAD by 21 in-flight writes) and `1,359` concepts vs `1,466` created — the 107 shortfall matched `concepts_collected=107` from one daemon GC sweep exactly. Wire-hygiene scan across all 3,423 responses and stderr found **`0` leaked DSNs, keys, or driver messages**.
- **SIGKILL crash boundary ([`evidence/0.5.0-vs-0.4.0/`](https://github.com/nrynss/lambo/tree/main/evidence/0.5.0-vs-0.4.0)):** The SIGTERM run lost no acknowledged writes. In the 0.5.0 SIGKILL run, `12` of `1,136` acknowledged writes were lost. The next writer replayed all `152` intents that had reached the store.
- **Durable write intents across embedder outages ([`evidence/mooshik-j3-durable-intents/`](https://github.com/nrynss/lambo/tree/main/evidence/mooshik-j3-durable-intents)):** 16 agents × 4 derives (`64` acked) closed immediately held the exact invariant `acked == applied-with-embedding + durable-intent` (`64 == 1 + 63`, `0` NULL embeddings). Re-attaching while the embedder endpoint was unreachable left all `62` pending intents unconsumed (`write_queue_replay_owed=62`, receipts `pending_replay`, `0` failed); the next healthy attach replayed all `62` (`applied_after_restart`, `64/64` embedded).
- **Multi-client stdio-to-HTTP forwarding ([`evidence/j4-live-multiclient/`](https://github.com/nrynss/lambo/tree/main/evidence/j4-live-multiclient)):** Starting a second `lambo serve` against a held session automatically forwards over the private Unix socket rather than exiting on lease refusal, preserving per-call `agent_id` attribution and logging `refused`, `proxying`, `refused_takeover`, and `proxying_stopped` in the shared ledger.

### Deterministic convergence (`lambo demo`)

The demo's rendered OUTCOME block is asserted **byte-identical** across two runs of the same scenario — no tolerance, ordering leniency, or rounding. Measured on August 16, 2026, at commit `0006824` ([`evidence/demo-determinism/`](https://github.com/nrynss/lambo/tree/main/evidence/demo-determinism)):

| What was measured | Result |
|---|---|
| Consecutive parity runs, frozen build | **100 of 100 passed, 0 failed** |
| Independent run-pairs, every diff line classified | **20 pairs, 0 unexpected differences** |
| Distinct places two runs can differ at all | **3**, all intentional, all outside the asserted block |
| Rendered scores across all 20 pairs | Identical |

The three permitted difference sites are the freshly-minted session id, a random node id quoted in the high-risk warning, and a narration line's canonization cycle index. Earlier live-cluster captures (`evidence/demo-live-1.txt` and `demo-live-2.txt`) predate the script-clock fix, when wall-clock recency jitter made identical output hold roughly nine runs in ten; those captures are preserved unedited alongside the parity captures.
