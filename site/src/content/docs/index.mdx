Connect Cursor, Claude Code, Codex, OMP, Pi, or a custom MCP client to shared memory. Your agents can record decisions and see which other work depends on them.

Agents that share a served session send writes to the same writer. The writer updates its in-memory graph and flushes changes to the configured store. A background worker promotes concepts as they meet the promotion policy’s evidence requirements.

```bash
# Try the deterministic two-agent REST API scenario with zero config
curl -fsSL https://github.com/nrynss/lambo/releases/latest/download/install.sh | sh
lambo demo
```

On Apple silicon, install the Metal build to run Candle BGE-M3 and SQLite locally. See [Installation](/lambo/installation/) to select a build and [Release notes](/lambo/release-notes/) for upgrade steps.

## Why structural memory

Multi-agent coding produces a flood of observations. Each agent sees one slice of the repository, writes notes in its own phrasing, and exits when the context window closes. Flat text files and plain vector RAG accumulate duplicates and cannot distinguish a passing remark from a load-bearing ruling.

Lambo models each session as a typed bipartite graph of interactions and concepts (`Entity`, `Logic`, `Constraint`, `Resource`, `Observation`) joined by structural edges. [Origin](/lambo/origin/) tells how working with coding agents led to a promotion model borrowed from veneration and canonization.

<div class="lambo-pillars">
  <div class="lambo-pillar">
    <h3>Consolidates duplicates</h3>
    <p>Lambo matches repeated concepts by canonical key and, where supported, vector similarity. Merge checks account for differences such as paths, versions, and identifiers.</p>
  </div>
  <div class="lambo-pillar">
    <h3>Promotes by evidence</h3>
    <p>The background worker checks evidence before promoting a concept. See <a href="/lambo/canonization/">Canonization</a> to understand the requirements under <code>Swarm</code> and <code>Solo</code>.</p>
  </div>
  <div class="lambo-pillar">
    <h3>Reports dependencies and conflicts</h3>
    <p>Recall can report a concept’s blast radius, recent edits, contradictions, and suspected supersession. Use <code>lambo_stale</code> to check for stale citations.</p>
  </div>
</div>

## Capabilities

<div class="lambo-capabilities">
  <div class="lambo-cap">
    <div class="lambo-cap-title">
      <span>Multi-session HTTP &amp; shared layers</span>
      <span class="lambo-cap-tag">[serve]</span>
    </div>
    <p>Serve multiple project sessions at <code>/mcp/s/&lt;session&gt;</code>, layer shared rules such as <code>general</code> into every recall, scope bearer tokens per credential, and route stdio clients by directory via <code>[[serve.projects]]</code>.</p>
  </div>
  <div class="lambo-cap">
    <div class="lambo-cap-title">
      <span>Durable names, contradictions &amp; staleness</span>
      <span class="lambo-cap-tag">lambo_stale</span>
    </div>
    <p>Bind normalized durable names to concept IDs, refute outdated beliefs with <code>against</code>, audit downstream dependents via <code>lambo_stale</code>, and isolate identical file paths across repos with <code>repo_scope</code>.</p>
  </div>
  <div class="lambo-cap">
    <div class="lambo-cap-title">
      <span>Multimodal &amp; calibrated retrieval</span>
      <span class="lambo-cap-tag">lambo_derive_image</span>
    </div>
    <p>Derive and recall images alongside text with EmbeddingGemma 2 or client vectors, backed by per-contract calibration rows, a startup embedder canary, <code>top_legs</code> scores, and optional RRF or redundancy filtering.</p>
  </div>
  <div class="lambo-cap">
    <div class="lambo-cap-title">
      <span>Pluggable backends &amp; operational telemetry</span>
      <span class="lambo-cap-tag">stats --store</span>
    </div>
    <p>Switch between SQLite, PostgreSQL (<code>pgvector</code>), CockroachDB, Memory, and an optional Elasticsearch <code>[recall]</code> tier in <code>lambo.toml</code>. Inspect every session lease-free with <code>lambo stats --store</code> and audit recall quality offline via <code>--ledger</code>.</p>
  </div>
</div>
