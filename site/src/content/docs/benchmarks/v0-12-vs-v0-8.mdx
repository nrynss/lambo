Both machines returned identical top-eight sets on all 20 queries. The Metal report
also checked the durable-name migration preview. It proposed zero bindings or
retirements in eight sessions, so this store needed only provisioning for the upgrade.

## Sequential results

Metal used a 2,663-concept SQLite session with the `general` layer. CUDA used a
separate 11,218-concept store. Each row compares builds on the same machine.

| Machine | Measurement | v0.8.0 | v0.12.0 |
| --- | --- | --- | --- |
| Metal | Recall p50 / p99 | 1.99 / 22.88 ms | 2.00 / 22.62 ms |
| Metal | Derive acknowledgement p50 | 0.50 ms | 0.50 ms |
| CUDA | Recall p50 / p99 | 12.09 / 57.96 ms | 12.32 / 30.34 ms |
| CUDA | Derive acknowledgement p50 | 28.57 ms | 5.58 ms |

On Metal, both builds applied all 330 replay calls and had matching final store
counts. The eight- and 16-agent v0.12.0 tests applied all 544 and 2,128 writes,
respectively.
