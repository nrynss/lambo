## Protect the session’s embedding space

<Badge text="Enhancement" variant="note" />

Writer attach and vector reads check the session’s embedding contract so vectors from a
different model or width cannot silently enter the same search space.

## Render structured recall in the web portal

<Badge text="New" variant="success" />

The read-only portal presents structured results alongside the verbatim recall block and
suppresses promotion gate figures that do not apply to Canonical concepts.

## Windows binary availability

<Badge text="Behavior change" variant="caution" />

This is the last release with a Windows binary. The shared local session endpoint introduced
in v0.3.0 uses Unix sockets.
