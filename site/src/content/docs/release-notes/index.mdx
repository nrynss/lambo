Start with the latest release, or read every release after the version you run today. Check
the breaking changes before replacing a writer, updating a store, or rebuilding a client.

[Full changelog](https://github.com/nrynss/lambo/blob/main/CHANGELOG.md) · [GitHub releases and downloads](https://github.com/nrynss/lambo/releases)

## Read the badges

- <Badge text="Breaking change" variant="danger" /> Check whether you need to provision a store, update configuration, or change client code.
- <Badge text="New" variant="success" /> A command, setting, or capability is available.
- <Badge text="Enhancement" variant="note" /> An existing feature works better or handles more cases.
- <Badge text="Behavior change" variant="caution" /> An existing feature behaves differently. Check whether it affects your setup.
