## Back up before writing new supersession edges

<Badge text="Breaking change" variant="danger" />

Once v0.8.0 writes a `SuspectedSupersedes` edge, v0.7.0 and earlier refuse to load that
session. Keep a pre-upgrade backup if you might roll back.

## Find stale citations and possible replacements

<Badge text="New" variant="success" />

Recall shows contradictions on ordinary memory and warns when a result depends on
contradicted knowledge. Use `lambo_stale` to list dependents. Writes can also produce
suggested replacement candidates that an agent can review and cite in `against`.

## Tune recall fusion and redundant results

<Badge text="New" variant="success" />

Set `[fusion] kind = "rrf"` to combine ranks across retrieval legs, or enable
`[selection] skip_redundant` to omit near-duplicate hits.

## Review EmbeddingGemma 2 thresholds

<Badge text="Behavior change" variant="caution" />

The calibrated contract tightens the merge threshold and the default layer similarity floor.
Set `[embedder] calibration = "off"` to restore the v0.7.0 values.
