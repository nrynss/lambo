## See stale focus warnings in the web portal

<Badge text="Enhancement" variant="note" />

`/api/inspect` now reports contradiction warnings, following MCP and CLI inspect. The portal
also shows fuzzy-resolution notes, and inspect ledger entries include `warnings` and
`contradicted`.

## Upgrade from 0.9.1

This release requires no provisioning or configuration changes.
