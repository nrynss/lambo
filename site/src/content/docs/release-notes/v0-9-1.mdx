## Check recall order on Qwen

<Badge text="Behavior change" variant="caution" />

When calibration is `builtin` and `[fusion]` is unset, Qwen contracts use reciprocal rank
fusion. Set the fusion kind explicitly to keep max fusion.

## See contradiction warnings in inspect

<Badge text="Enhancement" variant="note" />

`lambo_inspect` and `lambo inspect` warn when the focus is contradicted, using the same
ruling as recall.
