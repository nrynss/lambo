## Inspect store health without a writer

<Badge text="New" variant="success" />

`lambo stats --store` reports concept and edge counts, vector coverage, current writer
leases, and last-write times across the store. Add `--json` for scripts. Use
`lambo stats --missing-vectors` to list missing vectors for a session.

## Export query and document vectors

<Badge text="New" variant="success" />

`lambo embed` prints vectors and their embedding contract without opening a store. Export a
query vector and use `lambo recall --query-vector-as-text` with the original query text to
replay text recall.

## Explain how inspect matched its focus

<Badge text="Enhancement" variant="note" />

`lambo_inspect` adds `concept_type` and `resolution` to its structured focus, so clients can
tell whether a durable name, ID, exact text, or fuzzy match found the concept.
