## Handle the new shutdown receipt

<Badge text="Breaking change" variant="danger" />

Update receipt consumers for `close_unflushed`. It means the closing writer could not
confirm that it saved the intent. Recall before submitting the same concept again. Rust
callers must also add a wildcard arm when matching the now non-exhaustive `ReceiptAnswer`.

## Reduce contention between writes

<Badge text="Enhancement" variant="note" />

Concurrent derives spend less time holding the graph lock. The release’s 16-agent run
applied all 1,999 writes. Derives and actions that would close an acyclic relationship now
report the kind of cycle they would create.

## Load Candle only when a writer attaches

<Badge text="Enhancement" variant="note" />

A serve that proxies to the lease holder skips loading the model. The local identity cache
also avoids re-hashing unchanged model weights on subsequent starts.
