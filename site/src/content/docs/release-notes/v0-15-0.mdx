## Provision each store

<Badge text="Breaking change" variant="danger" />

Run `lambo provision` on each store before restarting its writers. The first run scans for
canonical keys that contain an empty stem and re-keys those concepts. A durable name with an
invalid key can prevent a session from opening. The error identifies the affected row, and
the changelog gives the repair procedure.

## Handle pending writes during embedder outages

<Badge text="Breaking change" variant="danger" />

In-session writes held due to an outage now answer `pending_replay`. Later writes from the
same agent wait behind them while the writer retries. Update clients and monitoring that
counted these outages as `failed`. See [MCP receipt states](/lambo/mcp/#lambo_stats).

## Discover sessions from the web portal

<Badge text="New" variant="success" />

`--discover-sessions` or `[web] discover_sessions = true` lets callers whose scope covers
every served session read live sessions created after startup. Leave the new key out of a
configuration you also use with v0.14.0.

## Repair drifted text vectors

<Badge text="New" variant="success" />

`lambo re-embed --rewrite-same-contract` rewrites text vectors under the existing contract
when a canary detects drift. A full re-embed requires `--repin-canary` if the live embedder
cannot reproduce the current pin.

## Open sessions with mixed hierarchy and citation cycles

<Badge text="Enhancement" variant="note" />

Sessions that v0.14.0 rejected because a child cited its own parent can load without a data
repair.
