## Provision existing stores and review platform builds

<Badge text="Breaking change" variant="danger" />

Run `lambo provision` on existing SQL stores to add the new session counters before
attaching the writer. Windows users can find the last Windows binary in
[v0.2.2](/lambo/release-notes/v0-2-2/).

## Share the local writer

<Badge text="New" variant="success" />

A shared session endpoint lets local clients use the same writer. The release also
introduced the Apple silicon Metal build.

## Select a promotion policy from configuration

<Badge text="New" variant="success" />

Set `promotion_policy` in `lambo.toml` or `LAMBO_PROMOTION_POLICY` in the environment to
choose between `Swarm` and `Solo`.
