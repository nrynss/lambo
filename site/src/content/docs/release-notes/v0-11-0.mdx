## Review web credential prefixes

<Badge text="Behavior change" variant="caution" />

A credential with an explicit `session_prefix`, including one inherited from serve, can read
matching sessions created after the web reader starts. Review each prefix before upgrading.
Exact names, wildcard credentials, and opt-in session listing keep their startup allowlist
scope.

## Support on-demand reads in custom stores

<Badge text="New" variant="success" />

Implement `GraphStore::session_readable` if your adapter should support dynamic prefix
reads. Bundled stores implement the read-only existence probe. Existing startup-served
sessions keep working with the default method.
