## Update authenticated Elasticsearch recall URLs

<Badge text="Breaking change" variant="danger" />

If a remote `[recall]` endpoint uses an API key, set `recall.url` to HTTPS. Point it at the
final address if it currently redirects. Plain HTTP with an API key is allowed only on
loopback.

## Use Elasticsearch as an embedder

<Badge text="New" variant="success" />

Set `[embedder] kind = "elastic"` to embed through an Elasticsearch Inference endpoint. You
can use that embedder with or without the optional Elasticsearch recall index.

## Keep pending writes after interrupted responses

<Badge text="Enhancement" variant="note" />

When an embedding response is cut off mid-body, hybrid writes retain their durable intent
for a retry on restart. HTTP response size limits also bound memory use.
