## Provision SQL stores and keep a rollback backup

<Badge text="Breaking change" variant="danger" />

Drain accepted writes, stop the writers, and take a consistent backup before running
`lambo provision` on existing SQL stores. The release adds two tables. To roll back after
using names or alias repair, restore the pre-upgrade backup. Follow
[Migration and memory repair](/lambo/migration/) for the full procedure.

## Update Rust names and snapshot code

<Badge text="Breaking change" variant="danger" />

`Memory::declare_synonym` requires an existing target. Supply the new `name` field in
`ConceptCitations` literals and preserve `GraphSnapshot.names` and
`GraphSnapshot.retired_aliases` in custom adapters and import or export tools.

## Cite concepts by durable name

<Badge text="New" variant="success" />

A normalized name stays bound to a concept ID and works in citations, contradictions,
inspection, and recall. Use `lambo names assign` for existing concepts and
`lambo names migrate` to preview legacy names and reviewed alias repairs.
