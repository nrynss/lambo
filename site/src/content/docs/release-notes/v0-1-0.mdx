## Share agent memory through MCP

<Badge text="New" variant="success" />

Agents can use stdio or HTTP to record concepts and actions in the same session and recall
them by meaning. The background canonization engine promotes concepts as they earn
structural evidence.

## Try the two-agent demo

<Badge text="New" variant="success" />

`lambo demo` runs a deterministic REST API scenario with the in-memory store and shows how a
recalled concept can carry a load-bearing warning.
