## Check rankings on calibrated Qwen stores

<Badge text="Behavior change" variant="caution" />

Qwen3 Embedding 4B gets measured constants at 1024 and 2560 dimensions. The constants affect
recall scoring, layer admission, and merge thresholds. For this release, setting
`[embedder] calibration = "off"` restores the previous constants.

## Request a specific output width

<Badge text="New" variant="success" />

Set `[embedder] dimensions` to send the OpenAI-compatible `dimensions` field. Its value must
equal the configured `dim`.

## Diagnose a fresh store or an uncalibrated contract

<Badge text="Enhancement" variant="note" />

Attach tells you to run `lambo provision` when a SQL store has no schema. `lambo serve`
warns on an uncalibrated embedding contract and `lambo stats` displays its calibration
status.
