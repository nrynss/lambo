## Update Rust struct literals

<Badge text="Breaking change" variant="danger" />

Code that constructs `RecallResult` or `ContractCalibration` with a struct literal must
supply the new fields. See the tagged changelog for the field list.

## Read recall strength scores

<Badge text="New" variant="success" />

`top_legs` reports the best score from each first-phase leg, and `confidence` combines the
scores where the chosen basis supports it. Treat `confidence` as a provisional diagnostic.
Its scale depends on the basis, embedding contract, and store size.

## Recover vector search after traversal falls through

<Badge text="Enhancement" variant="note" />

When a graph write invalidates a planned dependency traversal and recall falls back to
blended results, recall can run the vector search that it skipped.
