Use SQLite and the fixture embedder to write and recall your first concept. The release binary runs this example locally without a model download or an external service.

## Install the binary

Run the install script on macOS or Linux.

```bash
curl -fsSL https://github.com/nrynss/lambo/releases/latest/download/install.sh | sh
```

The script picks the binary for your platform, verifies its SHA-256 checksum, and installs it to `~/.local/bin`. Confirm it with `lambo --version`.

On Apple silicon, install the Metal build if you plan to run BGE-M3 in the Lambo process.

```bash
curl -fsSL https://github.com/nrynss/lambo/releases/latest/download/install.sh | LAMBO_FLAVOR=metal sh
```

See [Installation](/lambo/installation/) for version pinning and building from source.

## Configure a quick session

Create a `lambo.toml` that selects a local SQLite file and the fixture embedder. Both are included in the release binary.

```toml lambo.toml
[store]
kind = "sqlite"
path = "./lambo.db"

[embedder]
kind = "fixture"
dim = 1024
```

SQLite lets separate commands share the session file.

Create the schema once.

```bash
lambo --config lambo.toml provision
```

```
sqlite schema provisioned (init_schema, idempotent)
```

## Write memory

Write a concept to the `demo` session.

```bash
lambo --config lambo.toml derive --session demo --agent agent-a \
  --content "user schema" --kind entity
```

The one-shot command takes the session write lease, writes the concept, and releases the lease when it exits.

## Recall memory

Query the session for the concept you wrote. You can run this command while the session is served.

```bash
lambo --config lambo.toml recall --session demo --query "user schema"
```

```
user schema [Entity] (score 0.29)
```

The result includes the concept text, type, and score.

## Serve a session

Start an HTTP server to connect MCP clients to the session you created.

```bash
lambo --config lambo.toml serve --session demo --agent agent-a --transport http
```

Configure your MCP client to connect to `http://127.0.0.1:7700/mcp`. Send writes through MCP while the server holds the session lease.
